Each `@NPC Name:` line becomes that NPC's current activity. Non-`@` lines are shared scene setup.

Scene Presets

`Capture Current` stores the current director/ambient/world setup plus current NPC social overrides into the selected scene preset.
Runtime auto-matches presets by `Scene ID` first, then `Scene Name`. `Import Preset` also applies it immediately for DM prep.
