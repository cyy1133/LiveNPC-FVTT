World Activity

Each `@NPC Name:` line becomes that NPC's current activity. Non-`@` lines are shared scene setup.

Scene Presets

`Capture Current` stores the current director/ambient/world setup plus current NPC social overrides into the selected scene preset.
Runtime auto-matches presets by `Scene ID` first, then `Scene Name`. `Import Preset` also applies it immediately for DM prep.

NPC

One shared world-lore markdown is included for every NPC prompt.
Global social/ambient settings and map presets are managed in the `소셜 연기` tab.
NPC cards can override individual director options and bind to a specific FVTT session or owner.
Toggle NPCs on/off and set actor + soul/battle files. Use `Save NPC` / `Reload NPC` for NPC-only persistence.
Reaction distance: NPC responds only when source token is within `React Distance <= ft` (0 disables this gate). If source token is not resolved, it is skipped.
