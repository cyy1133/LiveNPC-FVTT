# 커뮤니티 소개글 (KR)

## 1. Discord용 짧은 소개글

`FVTT AI NPC Runtime`이라는 Windows 데스크톱 앱을 계속 확장하고 있습니다.

Foundry VTT, Discord, LLM을 하나로 연결해서 NPC가 캐릭터답게 대화하고, 전투에서는 현재 상태를 보고 턴을 수행하고, 비전투 장면에서는 `소셜 연기` 탭으로 ambient chatter와 짧은 NPC 간 follow-up까지 만들 수 있는 런타임입니다.

핵심 기능:

- EXE 기반 실행
- Discord + Foundry 통합
- Director / Ambient 분리 관리
- `@NPC` 월드 상태 메모
- Scene Preset 저장 / 적용 / Import / Export
- multi-session ownership routing
- DND5e 행동경제와 1차 전술 판단

## 3. 긴 소개글

`FVTT AI NPC Runtime`이라는 Windows 데스크톱 런타임을 계속 다듬고 있습니다.

목표는 단순합니다. Discord 대화, 비전투 소셜 장면, Foundry VTT 전투를 묶어서 GM이 NPC를 일일이 손으로 조작하는 부담을 줄이는 것입니다.

현재 되는 것:

- Discord, Foundry VTT, LLM을 한 앱에서 연결
- NPC별 Markdown 문서 기반 말투/행동 규칙 적용
- 전투 상태를 읽고 턴 행동 결정
- 죽은 적, HP 0 적, 비전투 참가 적 제외
- DND5e 행동경제 반영
- LOS, 벽, 경로, difficult terrain, cover를 고려한 1차 전술 판단
- `소셜 연기` 탭에서 Director와 Ambient를 따로 제어
- `@NPC 이름:`으로 현재 장면에서 각 NPC가 뭘 하는지 미리 지정
- Scene Preset으로 맵별 연기 준비를 저장 / 적용 / Import / Export
- 여러 FVTT 세션을 등록해서 ownership 분리나 결석 플레이어 대행 가능

이 도구는 특히 아래 상황에 맞습니다.

- 장기 캠페인에서 NPC가 많은 경우
- Discord와 Foundry를 같이 쓰는 경우
- 도시, 여관, 길드홀처럼 비전투 장면이 많은 경우
- 전투뿐 아니라 장면 분위기까지 유지하고 싶은 경우
